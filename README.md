# 💰 Profit Calculator

A simple Profit Calculator built using HTML, CSS, and JavaScript to calculate profits and losses.

## ✨ Features
- Add product details
- Calculate profits and losses
- Display product information in a table
- Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
